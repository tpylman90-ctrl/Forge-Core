# One-time request: pure dialogue bootstrap v1

Run one bounded CPU comparison from the authenticated, scratch-trained Forge
Seed v0.7 parent. Train four narrow interaction behaviors—recall within the
current conversation, accept a correction, ask for missing context, and admit
when a fact was never supplied—using deterministic fictional examples only.

Compare correctly paired target responses with an intent-matched shuffled
target control at identical update count. Score both candidates against the
source model once on a held-out wording and vocabulary exam, and compare
TinyStories validation loss. Keep all candidates research-only. Do not use
teacher-generated answers, personal conversation history, imported weights, or
memory data. Do not merge the candidate into the canonical checkpoint or an
Android build, regardless of outcome.
