# Forge Teacher v1 — verified lessons, local AI advice, real student training

## What is implemented

The teacher is **separate** from Forge's own neural weights. The
initial pipeline combines a deterministic curriculum planner with an
optional local pretrained language teacher. Only the planner and
verifier run by default in GitHub Actions; an externally pretrained
GGUF is NOT silently downloaded or invoked.

A teacher may suggest one of six skills: **copy, select, giver,
recipient, color, quantity**, based ONLY on aggregate development
scores. It may describe why it recommended a focus, but cannot
supply trusted answers, invoke actions, alter the final exam, or
edit personal memory. All submitted advice uses a strict JSON schema.

Lesson labels come from the original Forge Core rule-based instruction
generator. They are independently reconstructed and verified when
read back; modifying a lesson's label or prompt is rejected even if
the modified file's SHA256 is updated in a manifest. Teacher outputs
are untrusted suggestions, NOT supervised truth.

## First pilot

GitHub Actions workflow **Forge Teacher v1 — verified adaptive lesson
and neural student pilot**:
- generate 240 verified training and 120 development lessons;
- inspect the lesson manifest and original data/checkpoint hashes;
- start two identical copies of the verified compositional research
  candidate from source run 41649770774;
- compare gold words vs skill-balanced shuffled words, same 280
  optimizer steps, original TinyStories rehearsal and schedules;
- score short direct answers on the development set, separately
  report public-language loss regression;
- prepare, but **do not automatically train**, the next curriculum
  based on aggregate development feedback.

The original 14k-step from-scratch checkpoint remains untouched.
The teacher does not supply the student's pretrained weights. All
new weights are marked experimental.

## Optional locally installed AI teacher

After installing an appropriately licensed GGUF and llama.cpp
**locally** (no paid service or default download), generate an
advisory plan using aggregate DEVELOPMENT metrics:

    python -m forge_core.language.local_teacher \
      --llama-cli /path/to/llama-cli --gguf /path/to/licensed-model.gguf \
      --development-scores development-scores.json \
      --proposal-out teacher-advice.json

Then create an audited verified bundle:

    python -m forge_core.learning.teacher_v1 --out artifacts/teacher \
      --progress-json development-scores.json \
      --teacher-advice-json teacher-advice.json

The AI merely recommends a focus. Verified exercises and answers
are generated by Forge's own rules, and no user memories, emails,
health data, or private observations should ever be submitted to a
third-party teacher model or public CI.

## Feedback and gates

The student study writes \`next-development-scores.json\` with
only six integer correct/total pairs. The next training curriculum
can automatically devote more examples to struggling skills, while
retaining coverage of mastered skills.

**Development is not final validation.** Don't select or promote a
checkpoint based on the same 120 questions repeatedly. Require an
independent untouched exam, multiple seeds, free-form answers, and
retention of coherent story generation. No neural Why loop promotion,
Android deployment or claim of preschool-like comprehension yet.

Code: \`forge_core.learning.teacher_v1\`,
\`forge_core.language.local_teacher\`,
\`forge_core.neural.teacher_student_v1\`.


## First measured pilot (completed)

[Research Actions run 41668685911](https://github.com/tpylman90-ctrl/Forge-Core/actions/runs/41668685911)
successfully generated verified training/development bundles, trained
two matched research arms, scored 120 development examples, and saved
a feedback-selected NEXT lesson bundle. The parent scored 22/120,
verified training 19/120 and shuffled training 14/120; source
TinyStories loss changed 2.691088 → 2.725105. The teacher-guided
training change **failed to improve** the parent candidate.

The separate neural pointer study later reached 42/120 on
development, but only 41/360 on new synthetic cross-template examples.
The optional GGUF AI adviser was never invoked in GitHub Actions.
The student remains scratch-origin and **not preschool-capable**.
