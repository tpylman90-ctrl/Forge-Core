# Contributing to Forge Core

Forge exists to help people create regardless of formal training or financial resources. Contributions are welcome in geometric analysis, Blender automation, accessible interfaces, mesh validation, materials, documentation and reproducible benchmarks.

Start with a focused issue or pull request. Describe the problem, changes, test procedure and measured results. Include before/after views for geometry changes. Preserve originals and report known limitations. Prefer free tools, small reproducible fixtures, independent test cases and reasonable compute budgets.

Only submit work you have the right to contribute. Document third-party licenses and attribution; do not upload private assets, personal data, credentials or model weights without rights review. Code license selection is pending; do not assume public visibility grants redistribution rights. See the [charter](CHARTER.md) and [roadmap](docs/ROADMAP.md).
